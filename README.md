REDWOOD KITCHEN & CABINETRY — WEBSITE FILES

Website name: Redwood Kitchen & Cabinetry
This site uses the real product photos from the ZIP file you supplied.

FILES
- index.html: main website page
- styles.css: layout, responsive styling and colours
- script.js: search, categories, mobile navigation and WhatsApp product links
- products.js: product names, categories and descriptions
- images/: all supplied product images

OPEN LOCALLY
1. Extract the website ZIP file.
2. Open the Redwood_Kitchen_Cabinetry_Website folder.
3. Double-click index.html. The page opens in your browser.
4. Keep index.html, the CSS/JS files and the images folder together.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository, e.g. redwood-kitchen-cabinetry.
2. Extract the ZIP on your computer.
3. Upload the CONTENTS of the folder (index.html, styles.css, script.js, products.js, images folder and README) to the repository root. Do not upload only the ZIP.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then click Save.
7. Wait a few minutes. GitHub will show the published website link in Settings > Pages.

EDIT PRODUCTS
- Edit products.js to change product names, categories and descriptions.
- Put any added product images in the images folder and update the matching image path in products.js.
- Product prices are currently "Price on request" because no verified prices were provided. Update script.js if you want to display supplied prices individually.
- Product descriptions are deliberately cautious because measurements, materials, prices and stock details were not supplied.
- Images are named product-01, product-02, etc., and correspond to the uploaded photographs.
